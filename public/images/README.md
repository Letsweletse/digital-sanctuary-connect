
# Church Website Images

This folder contains all the images used on the Gate Gaborone Ministries website.

## Folder Structure

- `/hero` - Images for the homepage hero section
- `/sermons` - Sermon thumbnails and related images
- `/events` - Event banners and promotional images
- `/leadership` - Photos of church leadership team
- `/general` - General purpose images used throughout the site

## Guidelines for Images

- Hero images: 1920x1080px (16:9 ratio)
- Thumbnails: 800x600px
- Profile photos: 400x400px (1:1 ratio)
- File size should be less than 300KB when possible
- Preferred formats: JPG for photos, PNG for graphics with transparency

## Adding New Images

Upload new images through the admin panel. The system will automatically organize them based on the selected category.
